# Dr. Sambasivam Gnanasekaran — Academic CV website (Jekyll / Minimal Mistakes)

This repository contains a ready-to-publish Jekyll site (Minimal Mistakes theme) for Dr. Sambasivam Gnanasekaran.

## How to publish
1. Replace `<your-github-username>` and `<repo-name>` in `_config.yml` (optional).
2. Add your real `assets/profile.jpg` and `assets/Sambasivam_CV.pdf`.
3. Push to GitHub. Enable Pages on the repo settings.
